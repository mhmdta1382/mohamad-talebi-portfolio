# Mohamad Talebi — Portfolio Home (V5)

VS Code / Live Server ready static portfolio homepage.

## Run
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open `index.html` with **Live Server**.

## Hero artwork
- `assets/hero-portrait.png` is the supplied pixel portrait.
- The portrait itself is kept intact; the motion is added in CSS.
- Pixel clouds drift behind the portrait.
- A very subtle pixel shimmer moves across the artwork.
- The portrait has a small floating/breathing motion.
- `prefers-reduced-motion` disables the animations.

## Main stack
- HTML
- CSS
- Vanilla JavaScript
- Google Fonts: Jersey 15 + Space Grotesk
